1. TreeSet Overview
- Stores UNIQUE + SORTED elements.
- No duplicates, elements are automatically sorted.
- NO index.

2. TreeSet vs HashSet
HashSet -> Unique, no guaranteed order.
TreeSet -> Unique, sorted order.

3. Methods
- add(value), remove(value), contains(value), size(), isEmpty(), clear().

4. Special TreeSet Methods
Given: [10, 20, 30, 40, 50]
- first(): returns first (lowest) element (10).
- last(): returns last (highest) element (50).
- higher(x): strictly greater (> x). e.g., higher(30) -> 40
- lower(x): strictly smaller (< x). e.g., lower(30) -> 20
- ceiling(x): greater than or equal to (>= x). e.g., ceiling(30) -> 30, ceiling(35) -> 40
- floor(x): less than or equal to (<= x). e.g., floor(30) -> 30, floor(35) -> 30

*Note: Returns null if no such element exists (e.g., higher(50) -> null).*

5. Example
import java.util.*;
public class B {
    public static void main(String[] args) {
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        TreeSet<Integer> a=new TreeSet<>();
        for(int i=0;i<n;i++) {
            a.add(sc.nextInt());
        }
        System.out.println("First: "+a.first());
        System.out.println("Last: "+a.last());
        int x=sc.nextInt();
        System.out.println("Higher: "+a.higher(x));
        System.out.println("Lower: "+a.lower(x));
    }
}
